SAKE TIER PARTY v0.3 PWA

【公開】
ZIPを解凍し、index.html、sw.js、manifest.webmanifest、iconsフォルダをまとめてHTTPS対応の静的ホスティングへアップロードしてください。Netlify Dropはフォルダごとアップロードする方法が使えます（iPhoneのみの場合は環境によってアップロードしづらいことがあります）。

【iPhone/iPadへの追加】
Safariで公開URLを開き、共有メニューから「ホーム画面に追加」を選択。ホーム画面から起動し、評価を入力してください。

【保存】
評価はブラウザのlocalStorageに自動保存されます。ホーム画面アプリとSafariで保存領域が分かれる場合があるため、ホーム画面から一貫して起動してください。別端末には同期しません。バックアップボタンでJSONを保存し、設定から復元できます。

【オフライン】
オンラインで初回起動しService Workerのキャッシュが完了した後はオフライン起動できます。ブラウザのデータ削除や容量管理等でキャッシュが消える場合があります。

【注意】
PWAはApp Store配布のネイティブアプリではありません。公開URLを知っている人はアプリ自体にアクセスできます。評価データはサーバーには送信しません。
